## Why this happened

Two causes, both structural rather than careless.

**The drafts gate stopped conversion but not production.** Since roughly 10 September every run has been research-only, because unsent drafts were pending at the start of each one. Research kept compounding; nothing converted. Funnel C alone got three separate passes — the 3 September sweep, batch-10, and the 23 September top-ten ranking — and every one of them ended with contacts *banked*. Banked is not a queue. It has no order and no owner, so a verified contact like IxDF's can sit in it indefinitely without anything flagging that it is ready.

**Action items were written into documents that nothing reads as a task list.** "Enrich 2U, Berklee Online and Domestika" was recorded as the closing line of a research doc. The daily run reads the roster and the tracker for *exclusions* — who not to contact again — never for *to-dos*. So the instruction was preserved perfectly and executed never.

The fix for the second is cheap: this file is the task list, and the daily run should read it. The fix for the first is not a process change — it is sending the 28 drafts.
