**How the current guide works (✅ read 2026-09-19):**
- Every rate is a **range, per single spot**. Terms are **1 month / 3 months / 1 year** (6-mo = 2× the 3-mo, or steer to 1 yr). No length tiers — the guide does not price :15 vs :30 vs :60 differently.
- **Where in the range:** low end = local / small / unknown brand; **high end = major brands** (guide names Target, Best Buy, Nintendo, automotive, insurance, fast food, banking). Adobe-tier = high end.
- **Local = one city. Regional = up to 4 states or ONE large market (NYC/LA/Chicago/Atlanta/Philadelphia). National = nationwide.**
- Radio rates **include** the session ($250–350 for 60–90 min). TV / Digital Visual: $500 for a 2-hr session, **+$250 each additional hour**.
- Multiple spots: rate is negotiable; 1–2 spots is typical; a bulk discount is only suggested at 5+ (talent's call). **Lifts/edits/versions: don't grant unlimited — cap the count; discount lift usage 25–50% per spot.**
- **Value Menu** = the guide's new combo packages: bundle discount typically **15–25% off combined individual rates**, same term mirrored across channels. Use the bundle cell instead of adding two channels.
- Source Connect / ISDN: guide says do NOT bill separately — it's inside the rate.

## STEP 1 — decision tree (most jobs stop here)

1. **Budget under $1,000 AND (national scope OR in-perpetuity/worldwide OR broadcast with no client named)** → **PASS.**
   Say so in one line. Only price it if Spencer says "quote straight" — then use the grid, no discount.
   *Not this branch:* **local** radio/TV or capped non-broadcast is legit low-budget work — price it in Step 2.
2. **Budget at or above fair-market mid** (midpoint of the grid range for that cell) → **max out the budget.** Quote the ceiling, show the grid range so he sees the headroom.
3. **Everything else** → grid lookup, Step 2.

### Add-ons / rules (all ✅ from the guide unless marked)
- **Exclusivity** (none is included in any range): Tier 1 (auto, telecom, insurance, retail, banking, pharma, **tech/software**) **3–5× base** · Tier 2 (food/bev, beauty, apparel, airlines, travel) 2–3× · Tier 3 (sports gear, toys, pet, paint…) 1–2×.
- **Renewals:** session + usage + bump — 10–15%/yr local/regional, **40–50%/yr national or large brand** (digital visual: rate +10–20%). Put 30-day renewal notice in writing.

## Output format — DEFAULT for any pasted marketplace job

Plain text, not a code block. Bold section labels, blank line between blocks. The
**itemized GVAA table is the core** (Spencer, 2026-09-09 — each spot priced as its own
line so he can see the build and push on any part). Structure:

> **\<Job\>** — $\<budget\> · \<words\>w / \<length\> · \<category\> · \<licensing\> · \<N deliverables\>
>
> **Flags**
> - \<flag\>   (if genuinely none: **Flags:** none)
>
> **GVAA breakdown**
>
> | Deliverable | Length | Usage applied | GVAA basis (cell + where in range + why) | Amount |
> |---|---|---|---|---|
> | \<spot 1\> | :15 | Radio bundle, National, 1 yr | Value Menu $2,500–3,250 → high end (major brand) | $3,250 |
> | \<lift / spot 2\> | :15 | same recording | lift: 25–50% off usage — say which | $… |
> | \<add-on\> | — | — | e.g. +$250/extra session hr, own line | $250 |
> | **Total** | | | | **$…** (range if a cell is bracketed) |
>
> **At their $\<budget\>:** \<what that actually buys — or "nothing. \<the gap\>"\>
>
> **Verdict:** \<PASS  |  Counter at $\<X\>  |  Quote $\<X\>\>. Floor $\<Y\>. \<one line why\>
>
> **Verification footer** (RULE 0): — Verified (opened THIS session): \<page/tool — what\> or "none" / — Per card, not reopened: \<cells used, card date\> / — Bracketed \<item\> / — Unknown \<item\>

Floor = **low end of the same cell**, or the next term down at the high end. Log (below) only if he's pursuing it.

## Paste-ready website response — INCLUDE WITH EVERY BRIEF (Spencer, 2026-09-09)

After the internal read, give a response Spencer can paste straight into the site.
**Prose only — no tables, no bullets.** Brief, concise paragraphs. **Never open with "Hello, thank you" or any greeting/thanks.**

**If fairly priced or over budget:** one short paragraph — lead with any scope flag, then the rate.

**If underpriced (their budget < low end of the cell):** open with
*"Just to clarify a few things about the project before we get started:"* then, in prose:
1. Findings run together — scope discrepancies (territory vs creative, perpetuity on a short campaign, cutdown count, ambiguous "digital").
2. **As briefed** — one figure for the full scope at guide rates, scope named in the sentence.
3. **Rescoped** — one figure for the likely real need: a smaller package (shorter term / narrower territory / one channel), not a discount on the same rights. **Any grant briefed Worldwide is ALWAYS explicitly downsized in the rescoped tier — National or Regional — every time; if media are stacked, match the other media's territory and say why.**
4. The either/or in one sentence.
5. Close: "Within your budget of $\<exact figure\>, I can deliver \<exact scope: territory + term\>; \<what's excluded\> would be added on top." Name scope on both sides.

Two short paragraphs is the target.

**RULE 0:** grid cells are ✅ only if the live guide was opened THIS session (it's behind a sign-up gate — Spencer signs in). Otherwise they are "Per card (read 2026-09-19), not reopened" — never write "Verified" for them, and tag each guide claim inline where it's used. Anything the brief didn't state (client, real brand, "digital" meaning, territory) is a `[bracket]` or flag, never asserted. Every quote ends with the verification footer. Never invent a rate or multiplier that isn't in the grid — bracket it and open the live guide.

## Flag checklist (⚑ line — only the ones that apply)

- worldwide / national scope on a local or regional client
- in-perpetuity (esp. broadcast) — guide doesn't publish it; bracket + push for a term
- category exclusivity (tech/software, telecom, finance, auto = Tier 1, 3–5×)
- **ambiguous "digital"** — digital radio vs online video/pre-roll price differently
- "online ad" vs "non-broadcast" labels conflict — different price basis
- AI / synthetic-voice / voice-training rights
- unlimited lifts / versions — pin to a count
- missing client name · ambiguous deliverable count
- 1:00+ runtime labeled "online ad" — usually branded content mislabeled
- in-game / interactive use = separate licence

## Calibration (Spencer, since 2026-08-28)

- Marketplace: quote **fair-market-mid to win**, keep a real floor, don't undercut. Direct/agency work: high end for major brands.
- **Worldwide or in-perp on a sub-$1k budget = the trap (Avery, Delta Force). PASS, or quote straight — never take it at their number.**
- Budget ABOVE fair market → max out the budget, quote the ceiling.
- Never fabricate a rate.
