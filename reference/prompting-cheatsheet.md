# Prompting cheat sheet — getting more out of Bingo for less usage (2026-10-29)

## Name the target
- ✗ "check the drafts" → ✓ "Funnel S2, Yarnhub draft: is the re-voice line in?"
- ✗ "what's going on with McDonald's" → ✓ "McDonald's: is Eric Daley drafted yet?"

## Set the depth
- "quick answer" / "one line" / "yes or no" = I stop after the answer.
- "no footer" = skip the verification footer on an internal answer.
- "full research" = I go deep and source everything. Without a cue I default to thorough, which costs more.

## Give approvals up front
- "Build Funnel S1. Yes to Apollo credits, yes to scheduling, skip LinkedIn voice notes." One message, no stops.

## Batch related asks
- One message with three related asks beats three messages: each message reloads the whole conversation.

## One task per chat
- New, unrelated job → new chat. A long chat makes every later message more expensive. (I'll hand off on my own too: CLAUDE.md "Model routing".)
- Quick Voices.com quote → a fresh chat, ideally on Sonnet.

## Model picker (when you're choosing)
- **Haiku:** "what's X's email", "next invoice number".
- **Sonnet:** quotes, logging, tracker updates, "log", sweeps.
- **Opus:** pitches, hooks, coaching, research, strategy day to day.
- **Fable:** the big calls (the €10k plan, a big contract, a redesign). Rarely.

## Things that cost the most
Screenshots, browser crawls, many subagents at once, Apollo waterfalls, re-reading big files, very long chats. Say "text only" if you don't need me to look at a page visually.
